Python palindrome checker

A short program that reads a word or phrase from the user and checks whether it reads the same forwards and backwards.

About the project

The program reverses the input with the slice x[::-1] and compares it to the original. It prints true if they match and false if they do not.

  • Python

Source code

x = str(input())
                        if x == x[::-1]:
                            print("true")
                        else:
                            print("false")
